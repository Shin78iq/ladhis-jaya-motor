# Ladhis Jaya Motor

Website bengkel Ladhis Jaya Motor, melayani servis motor dan cuci motor.

## Halaman
index, tentang, layanan produk, galeri, kontak

## Teknologi
HTML5 dan CSS

## Cara Menjalankan
Buka file `index.html` di browser.

## Struktur Folder
- `Foto/` : gambar yang dipakai di website
- `style.css` : styling semua halaman
